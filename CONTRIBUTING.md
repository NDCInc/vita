# Contributing to Vita

Use [GitHub issues](https://github.com/NDCInc/vita/issues) for bugs and feature suggestions. Describe the steps, browser version, expected result, and observed result. Include a small fictional fixture if the issue depends on an import. Please keep résumés, transcripts, certificates, recordings, and other identifying information out of public reports and test cases.

See the [development guide](README.md#develop) and the [browser checks](qa/README.md) for prerequisites and commands. Changes to importing or exporting should include a reproducible check against a fictional document. Contributions to Vita's own software are distributed under its [MIT license](LICENSE).
